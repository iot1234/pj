## ปัญหาที่แก้ในรอบนี้

### 1. ชื่อปุ่ม LINE ไม่ตรงกัน ทำให้เริ่มต้นหน้าแอดมินไม่สำเร็จ
JavaScript ผูก event กับ `#line-oa-configure` แต่ HTML ยังมี `#line-oa-create` การเรียก `addEventListener` กับ element ที่ไม่มีทำให้เกิด exception และขัดจังหวะการเริ่มต้น admin console แก้ ID ใน `templates/admin/console.php` ให้ตรง พร้อมเปลี่ยนปุ่มเป็น “ตั้งค่า LINE Bot” และคำอธิบายให้ตรงกับบอทหลักบัญชีเดียว โดยไม่ย้อนงาน backend ที่แก้ไว้เดิม

เพิ่ม regression test ที่ตรวจชื่อ element จาก HTML จริง ชุด DOM จำลองเดิมสร้าง element ที่ไม่มีให้อัตโนมัติจึงตรวจไม่เจอ ก่อนแก้ HTML ตัวทดสอบใหม่ล้มเหลวด้วย `Missing real admin element: #line-oa-configure` หลังแก้ผ่าน

### 2. หน้าเลือกห้องรับผลโหลดเก่าทับผลล่าสุด
แก้ `public/assets/js/app.js` ให้ทุกการโหลดมีลำดับคำขอ และไม่ใช้ผลสำเร็จหรือข้อผิดพลาดจากคำขอที่ถูกแทนแล้ว ระหว่างโหลดแสดงข้อความ “กำลังโหลดห้องว่าง…” และไม่เปิดรายการเก่าให้กดจอง

### 3. โหลดห้องไม่สำเร็จแต่ยังเก็บรายการเก่าไว้
เดิมล้างเฉพาะหน้าจอ ไม่ล้างข้อมูลห้องในหน่วยความจำ เมื่อพิมพ์ค้นหาจึงสามารถแสดงรายการเก่ากลับมาได้ แก้ให้ล้างข้อมูลเมื่อโหลดล้มเหลว แยกข้อความผิดพลาดจาก “ไม่พบห้อง” และไม่วาดรายการจนกว่าจะโหลดสำเร็จ

### 4. รีเฟรชแล้วตัวกรองประเภทและชั้นหาย
เก็บตัวกรองเดิมเมื่อค่านั้นยังมีในรายการใหม่ รีเซ็ตเฉพาะตัวเลือกที่ไม่มีแล้ว เพิ่มการทดสอบผลตอบกลับสลับลำดับ โหลดล้มเหลว และการรักษาตัวกรองรวม 5 ข้อ ก่อนแก้ล้มเหลว 4 ข้อ หลังแก้ผ่านทั้ง 5 ข้อ

### 5. ชุดทดสอบ LINE ค้างเพราะยังจำลองขั้นตอนเก่า
ปรับ interaction tests ให้ตอบ GET ของ OA 0 ก่อนทดสอบการบันทึกด้วย PUT และใช้ปุ่มตั้งค่าใหม่ เพิ่มการตรวจว่าห้ามเลือก OA อื่นและตัวเลือกผูกบัญชีมีเฉพาะบอทหลัก ไม่ลบหรือข้ามข้อทดสอบเดิม กำหนด timeout ในคำสั่งทดสอบเพื่อไม่ให้ค้างไม่สิ้นสุด

## สภาพแวดล้อมที่ยังต้องจัดการ

PHP ใน PATH เป็น 8.5.8 แต่ไม่มี php.ini ที่โหลดอยู่ จึงขาด pdo_mysql/curl/mbstring/gd/fileinfo/openssl และตั้งขนาดอัปโหลดต่ำกว่าที่โปรเจกต์ต้องการ ใช้ ini แยกในพื้นที่ private ของโปรเจกต์แล้วทดสอบส่วนขยายได้ครบ ไม่แก้ php.ini กลางหรือการตั้งค่าของโปรเจกต์อื่น

`.env` ปัจจุบันเป็น production, DB_HOST ไม่ใช่ loopback และ APP_URL ยังมีตัวแปรอ้างอิงของแพลตฟอร์ม จึงไม่ผ่านการรันตรงบนเครื่อง local ไม่ได้เปลี่ยนหรือแสดงค่าลับ และผลนี้ไม่ได้ยืนยันว่า environment ที่แพลตฟอร์มใช้งานจริงผิดด้วย ตัวตรวจยังแจ้งว่ามี ADMIN_PASSWORD อยู่ ควรนำออกเมื่อยืนยันว่ามีบัญชีเจ้าของแล้ว ไม่ได้ลบให้โดยอัตโนมัติ

ต้องแยก local/staging configuration และฐานทดสอบก่อนเปิดเว็บแบบ local; ห้าม import install.sql ทับฐานเดิม ห้ามเปลี่ยน APP_KEY ที่ใช้งานอยู่เพื่อให้รันผ่านเฉย ๆ

## งานก่อน deploy ที่ยังไม่เสร็จ
ชุด MySQL integration เช่น `tests/line_oa_mysql.php` บรรทัด 32/59 และ `tests/line_platform_mysql.php` บรรทัด 22/23 ยังเรียกสร้าง OA เพิ่ม ขณะที่งาน backend เดิมเปลี่ยน create() ให้ปฏิเสธ ต้องปรับสัญญาการทำงานและ fixture ให้ตรงกันและรันทดสอบกับ MySQL แยกก่อน deploy ไม่ได้ลดเงื่อนไขความปลอดภัยหรือแก้ schema จริงเพื่อทำให้ผลทดสอบผ่าน

ยังไม่ตรวจว่าฐานจริงมี OA อื่นหรือคิวเก่าที่อ้าง OA อื่นหรือไม่ ต้องวางแผนการย้ายข้อมูลส่วนนี้ก่อนใช้รุ่นบอทเดียว รวมถึงตรวจ migration 015, สิทธิ์ runtime, worker, การกู้ backup และการทดสอบ LINE/สลิปจริงบน staging อย่างควบคุม

```powershell

```
