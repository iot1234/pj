# แก้มิเตอร์ขาดงวดและการกลับมาแก้ไข — 20 กันยายน 2026

## ปัญหาและการแก้ไข

หน้าเดิมถือว่าค่า previous ที่ว่างเป็นเดือนแรกหน่วยศูนย์ ทั้งที่อาจมีผู้พักแต่ขาดประวัติ ฝั่ง record กลับตรวจเดือนและ occupancy อย่างเข้มงวด จึงกรอกได้แต่บันทึกไม่ได้

เพิ่ม MeterReadiness เพื่อจำแนกเลข ณ วันเข้าพัก ประวัติงวดก่อนของผู้พักรอบเดียวกัน การตั้งต้นห้องว่าง ประวัติขาด ผู้พักซ้อน และเลขตั้งต้นไม่ตรง อ่าน prior period และ prior occupancy พร้อมตัวเลขจาก query เดียวกัน เมื่อประวัติไม่พร้อมไม่เปิดช่องให้กรอกเพื่อข้ามเงื่อนไขหรือสร้างเลขศูนย์แทน

กรณี METER_HISTORY_GAP ส่งเดือนก่อนที่ต้องใช้และเดือนแรกที่ขาดจริงกลับไปด้วย หน้าเว็บมีปุ่ม **เติมงวด ...** และ **กลับงวด ...** การเปลี่ยนเดือนเก็บร่างแยกตามเดือนและห้องในหน่วยความจำของหน้า ไม่ทิ้งค่าห้องอื่นเมื่อบันทึกทีละห้อง

ร่างในหน่วยความจำไม่ใช่ข้อมูลที่บันทึกบนเซิร์ฟเวอร์: ปิดแท็บ รีเฟรชทั้งหน้า หรือออกจากหน้าพร้อมยืนยันทิ้งร่างอาจสูญเสียค่าที่ยังไม่บันทึก เลขที่บันทึกสำเร็จแล้วอยู่ในฐานข้อมูลตามเดิม

## การป้องกัน

ฟอร์มมิเตอร์ล็อกช่องของแถวที่กำลังส่งและกันส่งซ้ำ ไม่เปลี่ยนเดือนหรือเมนูระหว่างบันทึก เมื่อผิดพลาดข้อความอยู่กับแถวห้องและคืนช่องกรอกให้ลองใหม่ เมื่อโหลดทั้งรายการล้มเหลวจะไม่เปิดรายการเก่าให้บันทึก ร่างยังรอให้โหลดใหม่สำเร็จได้

ส่ง edit version ที่เซิร์ฟเวอร์สร้างเอง ไม่มีช่องให้ผู้ใช้กรอก โดยผูกกับห้อง เดือน ประเภทมิเตอร์ ข้อมูลเดิม ผู้พัก และค่าก่อนหน้า ฝั่ง record เปรียบเทียบหลังล็อกและตรวจฐานก่อนเขียน หากเปลี่ยนจากอีกหน้าต่างจะไม่ทับเงียบ ๆ พร้อมปุ่มใช้ข้อมูลล่าสุดของห้องนี้ซึ่งต้องยืนยันก่อนทิ้งร่าง เงื่อนไข version เป็นทางเลือกสำหรับ API client เดิม แต่หน้าเว็บรุ่นนี้ส่งทุกครั้งเมื่อได้รับ version จากรายการ

เลขมิเตอร์งวดล่าสุดที่ยังไม่มีบิลหรืองวดถัดไปอ้างอิงสามารถแก้และบันทึกใหม่ได้หลายครั้ง การส่งค่าซ้ำเดิมเป็น no-op ที่รักษาประวัติ ไม่ปลดล็อกบิลหรือประวัติอ้างอิงเพื่อบังคับแก้ทุกงวด ไม่มีการลบ ย้ายผู้พัก หรือแก้ตัวเลขจริงให้อัตโนมัติ

## มือถือ

จอไม่เกิน 760 พิกเซลแสดงตารางเป็นการ์ดรายห้อง ช่องน้ำและไฟอยู่คู่กัน มีหัวข้อก่อนหน้า ปัจจุบัน และหน่วย ไม่ตรึงคอลัมน์จัดการให้บังช่องกรอก พื้นที่กดปุ่มอย่างน้อย 44 พิกเซล ข้อผิดพลาดอยู่ภายในการ์ด ไม่พึ่ง toast อย่างเดียว
