# ตรวจระบบทุกฟีเจอร์และตัดสิทธิ์แอดมิน — 2 ตุลาคม 2026

## ผลการตรวจ

ตรวจและแก้โปรเจกต์ PHP/MySQL ใน `php-mysql` ซึ่งเป็นระบบปัจจุบัน
เริ่มจาก commit `705c745` ครอบคลุม FR-01–FR-16 ทั้งหน้า public/resident
และ 11 หน้าหลังบ้าน รวม API, domain services, session, LINE, worker,
schema, migration, installation และ readiness
โฟลเดอร์ Node รุ่นเก่า `newap`/`ap` ไม่ใช่แอปที่ใช้ในการตรวจรอบนี้

หลังแก้ มีบทบาทเข้าสู่ระบบเฉพาะ **เจ้าของระบบ (`owner`)** และ
**ผู้ใช้งาน (`resident`)** ผู้เยี่ยมชมยังดูห้องและจองแบบไม่เข้าสู่ระบบได้
บัญชีแอดมินเดิมถูกระงับถาวรโดยเก็บประวัติไว้ ไม่ยกระดับเป็นเจ้าของ
ทุกฟีเจอร์หลังบ้านเป็นสิทธิ์เจ้าของระบบ

ไม่พบ failure ที่ยังค้างในชุดทดสอบภายในที่รันรอบสุดท้าย
ข้อความนี้ไม่รับรองบริการภายนอกหรือข้อมูลของระบบที่เผยแพร่จริง
ไม่มีการรัน migration บนฐานที่ตั้งค่าใน `.env`, deploy, ส่ง LINE จริง
เรียก provider ตรวจสลิปจริง หรือโอนเงิน

## ข้อจำกัดและสิ่งที่ยังต้องยืนยัน

- **LINE จริง:** ต้องตรวจ token/secret/OA, webhook Verify, redelivery,
  quota และ push delivery บนระบบ staging ที่มี credentials ของเจ้าของ
  ผล mock ไม่ยืนยันสิ่งเหล่านี้
- **ตรวจสลิปจริง:** ต้องตรวจ SlipOK/EasySlip key/โควตา และสลิปจริง
  ใน provider account ที่ตั้งใจใช้ การทดสอบนี้ไม่ยืนยันเงินเข้า
- **โครงสร้างเผยแพร่:** ยังไม่ได้ build Docker, HTTPS/proxy/worker/cron
  บน host จริง หรือทดสอบ backup/restore ของข้อมูลจริง
- **Phone-only:** คนที่รู้เบอร์อาจเข้าแทนได้ตามนโยบายที่โปรเจกต์กำหนดไว้
  ผู้ใช้กรอกเฉพาะเบอร์ ไม่ใช้ OTP/password/PIN/activation code
  คอลัมน์ credential เก่ายังคงไว้เพื่อ compatibility แต่ไม่ถูกใช้สร้างรหัสหรือยืนยันตัวตน
- **รอบพักในเดือนเดียว:** ระบบยังไม่รองรับย้ายผู้พักใหม่เข้าห้องเดิมในเดือน
  ที่มี occupancy เดิมและแบ่งค่าใช้จ่ายตามวัน ต้องเป็นการเพิ่มนโยบาย proration
- **ยอดโอน:** ช่วงยอดใกล้กันมีสล็อตจองยอดต่างกันสูงสุด 99 ค่า
  เมื่อเต็มระบบหยุดให้รอ/กู้คืน ไม่สร้างยอดชนกัน
- **ตัดบิล:** ไม่มีการกดอนุมัติชำระด้วยมือ สลิป rejected ไม่ถูกเปลี่ยนเป็น paid
  โดย Owner; ผล provider ที่ไม่แน่นอนอยู่ pending เพื่อ retry/close ตามกฎ
- **ขอบเขตผลิตภัณฑ์:** PHP rewrite นี้ไม่รวม modules ของแอป Node เก่า
  เช่นพัสดุ/แจ้งซ่อม/สัญญาหลายหอ การตรวจไม่ได้นำ modules เหล่านั้นกลับมา

ข้อจำกัดเหล่านี้ไม่ถูกแสดงว่าเป็น feature ที่ตรวจผ่านภายนอกหรือทำได้แล้ว

## นำรุ่นนี้ไปใช้กับฐานเดิม
