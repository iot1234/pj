# พาไปแก้ข้อมูลก่อนออกบิลและกลับมาทำต่อ

## การเปลี่ยนแปลง

หน้าใบแจ้งหนี้แสดงสาเหตุที่ยังตรวจยอดไม่ได้ พร้อมปุ่มไปแก้ตรงจุด แทนการปิดปุ่มโดยไม่บอกทางไปต่อ เช่น ยังไม่ยืนยันค่ารายเดือน เลือกเดือนอนาคต ไม่เลือกห้อง หรือชื่อค่าใช้จ่ายอื่นกับยอดเงินไม่สอดคล้องกัน ค่า 0 บาทยังใช้ได้เมื่อตั้งใจยืนยันว่ารายการนั้นไม่เรียกเก็บ

เพิ่ม `GET /api/admin/bills/candidates?period=YYYY-MM` ภายใต้สิทธิ์ admin เพื่อเลือกห้องจากช่วงเข้าอยู่ของเดือนที่ออกบิล ไม่อิงสถานะผู้พักปัจจุบันอย่างเดียว ห้องที่มีบิลแล้วไม่เปิดให้เลือกซ้ำ ไม่สร้างหรือเปลี่ยนข้อมูลผู้พักจากการอ่านนี้

หน้าแนะนำระบุประเภทปัญหาและปุ่มไปหน้าที่เกี่ยวข้องจากรายการปลายทางที่กำหนดในโค้ด ไม่ใช้ URL หรือ selector อิสระจากคำตอบ API รองรับค่ารายเดือน มิเตอร์ขาดงวด เลขมิเตอร์ ณ วันเข้าพัก ผู้พักไม่ตรงรอบ และการอ่านผลเดิมเมื่อไม่ทราบว่าบันทึกสำเร็จหรือไม่

## วิธีใช้

เมื่อหน้าออกบิลแจ้งว่าไม่พร้อม ให้กดปุ่มในรายการปัญหา เช่น **ไปยืนยันค่ารายเดือน** หรือ **ไปจดมิเตอร์ห้องนี้** ระบบเก็บเดือน ห้องที่เลือก ชื่อรายการอื่นและยอดเงินไว้ในแท็บเดิม เมื่อบันทึกข้อมูลจริงแล้วกด **กลับไปตรวจยอด** เพื่ออ่านข้อมูลและคำนวณใหม่ การกลับมาไม่ออกบิลให้เอง ยังต้องตรวจรายละเอียดและยืนยันแยก

ช่องรายการอื่นเป็นชื่อค่าใช้จ่าย ไม่ใช่ช่องยอดเงิน หากมีชื่อแต่จำนวนเงินเป็น 0 จะมีคำแนะนำและปุ่ม **ไม่คิดรายการอื่น** ซึ่งต้องยืนยันก่อนล้างชื่อและยอด ระบบไม่แปลงข้อความชื่อรายการเป็นเงินให้เอง

เมื่อเลือกเดือนที่ไม่มีผู้พักตามประวัติ จะบอกให้ตรวจรอบเดือนแทนการนำผู้พักปัจจุบันไปคิดย้อนหลัง ในกรณีรอบเข้าอยู่เดิมไม่อยู่ในรายการผู้พักที่ยัง active ระบบแจ้งข้อจำกัดและไม่เปิดฟอร์มของผู้พักคนอื่นแทน

## การป้องกัน

ล็อกฟอร์มขณะตรวจยอดและยืนยันออกบิล กันกดซ้ำและเปลี่ยนหน้า เก็บร่างเมื่อการโหลดห้องล้มเหลว แยกผลอ่านรายชื่อบิลกับห้องที่ออกบิลได้ จึงยังดูบิลที่โหลดสำเร็จได้แม้ส่วนห้องมีปัญหา คำขอเก่าไม่ทับงวดใหม่

รักษาการตรวจสิทธิ์ การยืนยันค่ารายเดือน การตรวจมิเตอร์และผู้พัก การตรวจ preview token และการป้องกันบิลซ้ำบนเซิร์ฟเวอร์ ไม่ปลดล็อกบิลหรือมิเตอร์ที่มีเอกสารอ้างอิงเพื่อบังคับให้ผ่าน

ร่างแก้ไขก่อนออกบิลได้หลายครั้ง แต่เป็นข้อมูลในหน่วยความจำของแท็บ ไม่ใช่ร่างถาวร การปิดแท็บหรือรีเฟรชทั้งหน้าอาจทำให้ร่างหาย ข้อมูลที่บันทึกแล้วอยู่ใน MySQL ตามเดิม

Edge headless **67 กรณีผ่าน** (LINE 11, หน้าเว็บเดิม 22, บริการภายนอก 6, มิเตอร์ 11, ขั้นตอนออกบิลใหม่ 17) เส้นทางใหม่ตรวจตั้งแต่ไปแก้ค่ารายเดือน/มิเตอร์ กลับมาร่างเดิม ตรวจยอด ยกเลิกแล้วกลับแก้ และยืนยันออกบิลเพียงครั้งเดียว ใช้ HTML/CSS/JavaScript จริงกับ API จำลอง ปิดกั้นเครือข่ายภายนอก ไม่ใช่การออกบิลใน production และไม่ใช่ Safari/iPhone จริง
