# เมนูข้อความโดยไม่มีอิโมจิ — 20 กันยายน 2026

แก้ source ของระบบ PHP/MySQL โดยตรง ไม่ได้แก้หรือสร้างภาพแทนหน้าเว็บ

## การเปลี่ยนแปลง

ลบสัญลักษณ์ตกแต่งจากเมนูแอดมิน ผู้พัก และเมนูมือถือ รวมถึงหน้าตั้งค่า เข้าสู่ระบบ ข้อความสำเร็จ และหน้าต่างยืนยัน ปุ่มสัญลักษณ์เปิดเมนูและปิดหน้าต่างเปลี่ยนเป็นข้อความไทย พร้อมคง event attributes และชื่อสำหรับการเข้าถึงไว้ ลูกศรในแถวบิลเปลี่ยนเป็นคำว่า “ดูบิล” และเอาอิโมจิออกจากข้อความยืนยันของ LINE Bot สองตำแหน่ง

นำกฎ CSS ความกว้างช่องไอคอนออก เพื่อไม่ให้ข้อความเมนูถูกบีบเหลือ 24 พิกเซล จัดตำแหน่งตัวเลขแจ้งเตือนบนมือถือใหม่ให้ไม่ทับข้อความ ปุ่มข้อความยังมีพื้นที่กดอย่างน้อย 44 พิกเซลในแนวตั้ง

คงชื่อระบบ โลโก้ตัวอักษร รูปห้อง อักษรย่อผู้ใช้ ตัวเลขแจ้งเตือน สีสถานะ ข้อความเตือน เครื่องหมายคำนวณ หน่วยเงิน ฟอร์มบังคับกรอก และ QR ไว้ ไม่แก้ข้อมูลผู้ใช้หรือกรองข้อความที่ผู้ใช้เคยกรอก ไม่มีการแก้ schema ค่าลับ การชำระเงิน หรือเงื่อนไขสิทธิ์

## การทดสอบ

- PHP unit/contract 110 ผ่าน; JavaScript 107 ผ่าน รวม regression ใหม่สำหรับเมนูข้อความ 7 ข้อ
- PHP lint 78 ไฟล์, JavaScript syntax 2 ไฟล์, shell syntax, LINE bot offline, monthly billing CLI, worker contract, install SQL bundle และ git diff --check ผ่าน
- Microsoft Edge headless 22 กรณีผ่าน ด้วย HTML/CSS/JavaScript จริงของโครงการและ API จำลอง บล็อกเครือข่ายนอก loopback ไม่มีการสร้างห้องหรือบัญชีจริง
